Proxmox VE 系統更新程序

適用環境：PVE 8.x / 9.x | 免費社群源設定與完整更新流程

1. 準備與檢查

在執行任何更新之前，請確認備份狀態並檢查目前的 PVE 服務與節點狀態。

  • 確認重要 VM / LXC 容器已完成備份（PBS 或本地備份）。
  • 若為 Cluster 多節點環境，請確認 Migration 管道正常。

2. 免費社群源設定 (No-Subscription Repo)

若無購買企業訂閱，請關閉企業源並啟用非訂閱社群源，避免更新時出現 401 Unauthorized 錯誤。

Step A: 關閉 Enterprise 企業套件源 (安全停用)

[ -f /etc/apt/sources.list.d/pve-enterprise.list ] && sed -i "s/^deb/#deb/g" /etc/apt/sources.list.d/pve-enterprise.list

Step B: 新增 No-Subscription 免費套件源 (以 Debian Bookworm 為例)

cat <<EOF > /etc/apt/sources.list.d/pve-no-subscription.list
deb http://download.proxmox.com/debian/pve bookworm pve-no-subscription
EOF

3. 執行系統更新

更新套件清單並執行完整更新。在 PVE 環境中，務必使用 dist-upgrade 以確保核心與套件依賴完整更新（請勿僅使用 upgrade）。

Step A: 更新套件索引與檢視升級項目

apt update && apt list --upgradable

Step B: 執行系統完整升級

apt-get dist-upgrade -y

4. 重啟與核對版本

若更新內容包含 Linux Kernel 核心更新，建議重啟 PVE 實體主機以應用新核心。

Step A: 檢查是否需要重啟 (核心變更)

uname -r

Step B: 重啟 PVE 主機

reboot

Step C: 重啟後核對 PVE 版本

pveversion -v
