qBittorrent 靜態版更新指南

環境 PVE LXC (Debian)  |  主機 IP 192.168.1.120:8080

步驟一：前置安全備份

由於外掛 NAS 資料夾，本客體機不支援快照。更新前請手動在容器內備份執行檔與包含帳密、種子狀態的設定檔。

步驟二：連線與執行更新

請使用 SSH 或透過 PVE 控制台登入，並在 root@qBittorrent:~# 提示字元下執行以下整合指令：

# 1. 備份現有的執行檔與設定檔
cp /usr/bin/qbittorrent-nox /usr/bin/qbittorrent-nox.v522.bak
rm -rf ~/.config/qBittorrent_bak_old
mv ~/.config/qBittorrent_bak ~/.config/qBittorrent_bak_old 2>/dev/null
cp -r ~/.config/qBittorrent ~/.config/qBittorrent_bak

# 2. 停止當前服務並下載官方最新修正版靜態執行檔
systemctl stop qbittorrent-nox
wget -O /usr/bin/qbittorrent-nox https://github.com/userdocs/qbittorrent-nox-static/releases/latest/download/x86_64-qbittorrent-nox

# 3. 賦予檔案執行權限並重啟服務
chmod +x /usr/bin/qbittorrent-nox
systemctl start qbittorrent-nox

步驟三：檢查與修復

執行以下指令確認系統狀態是否已回到綠色的 active (running)：

systemctl status qbittorrent-nox
💡 故障排除與小提示：
  • 更新後若 WebUI 卡死（顯示已在運行卻無法連線），請執行：
    rm ~/.config/qBittorrent/qBittorrent.lock 清除鎖定檔後重啟服務。
  • 確認 WebUI 原本掛載的 NAS 下載路徑與種子皆正常做種即可。
